# nasa-maze

Mapa interactivo para planificar Marswalks seguras: rutas, condiciones y capas de datos de misiones de la NASA en una sola vista.

Proyecto para el reto **Interplanetary Survival Guide: Martian Map** — NASA Space Apps Challenge 2026.

## Estructura
- `pipeline/` — descarga y procesamiento de datos (GDAL → COG/PMTiles)
- `web/` — frontend del mapa
- `infra/` — configuración de GCP
- `.github/workflows/` — CI/CD

## Datos
Built with NASA data.
